Add a new item

Three short steps. Fill in what you know. You can change any of this later.

  1. 1 DetailsName and category
  2. 2 StockUnit, store and reorder level
  3. 3 PriceCost and supplier

3 things to fix before we can save

Everything else you typed is kept. Tap a problem to jump to it.

    1

    Details

    What is it, and what kind of thing is it?

    Use the name people say out loud, e.g. “Whiteboard Marker, Red”.

    The group it belongs to. It helps people find it.

    Leave it empty and we’ll make one, like STA-0031.

    Anything that helps tell it apart: colour, size, brand.

    2

    Stock

    How you count it, where it lives, and when to reorder.

    How do you count it? Required

    Pick the word you’d use when counting: “18 pieces”, “3 boxes”.

    Put 0 if none have arrived yet.

    When stock drops to this number, the item appears in Needs attention so you remember to order more.

    3

    Price

    What one costs the school. This works out the value of stock.

    The price for one unit, in rupees. Type only the number.

    Rs

    Who you normally buy it from.

    Nothing is saved until you press Save item.

    Cancel

    Good to know

    • Only the boxes marked Required must be filled in.
    • Not sure about the price? Check the last bill from the supplier.
    • You can add stock later with Receive stock.

    Need a hand?

    Ask the office on extension 104. They can add the item for you.
